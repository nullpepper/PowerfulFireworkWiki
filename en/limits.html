限制与边界

同样是一场“烟花”，实现方式不同，撞上的硬限制也不同：普通粒子受制于视距与视频设置，force 粒子受制于渲染引擎预算，发包烟花则受制于实体渲染距离与客户端本地模拟。

本页结论按 26.3 服务端源码与官方文档逐条核对，完整出处见文末考据依据。

在编排演出前，先摸清这三道墙的边界：

粒子（不传 force）​

普通粒子从服务端发出到最终渲染，需连过四道关卡，任一环节拦截即消失：

关卡判定基准阈值超出表现
服务端广播玩家实体坐标32 格收不到数据包
客户端准入相机坐标32 格收包后直接丢弃
视频设置客户端粒子档位全部 / 减少 / 最少“减少”保留约 2/3，“最少”全丢
引擎收容对应渲染队列队列上限 + 概率收容图案随机漏点、缺角
  • 两个独立的 32 格：服务端按玩家位置发包，客户端在 ClientLevel.doAddParticle 中按相机位置二次判定。玩家抬头、后退或切视角都会导致临界点粒子断流。
  • “最少”档等于全丢：“减少”档会将约 1/3 粒子降级为“最少”档；“最少”档仅对 alwaysShow = true 的粒子有 10% 保留率，而 Bukkit 的 CraftWorld.spawnParticle 底层传给该参数的恒为 false。
  • 排队与概率收容：粒子先入 ParticleEngine.particlesToAdd，下一 tick 才合入队列并开始计算寿命。超量时按剩余空间的平方概率收容，表现为随机丢点而非整体变淡。
  • 裁剪不管逻辑：视锥裁剪每帧仅对粒子中心做点测试；视野外与背面的粒子虽不绘制，但仍在后台 tick 并消耗寿命。
  • count 的两种语义：count > 0 为偏移盒内高斯随机撒点；count = 0 为单点发射模式（速度 = 偏移向量 × speed）。精确摆点必须固定 count = 1 且偏移归零。
  • 短寿命依赖重绘：dust 的 scale 同时缩放体积与寿命，点越小消失越快，点阵图形通常需按 5–10 tick 间隔周期性重发。

粒子（开启 force）​

force = true 仅放行前两道关卡（距离与视频设置），进入引擎后的规则与普通粒子完全一致：

  • 广播半径扩至 512 格：由调用方布尔值决定，与粒子类型无关，并非全服无限可视。
  • 无视距离与视频设置：跳过相机 32 格检查，且强行穿透“减少/最少”档位——代价是剥夺低配玩家的帧率保护。
  • 共享全局引擎预算：队列上限、1 tick 延迟、视锥裁剪与寿命照旧。预算吃满时，会连带挤掉玩家脚边火焰、他人拖尾等所有原版粒子。
  • 高并发与单包风险：单包 count 无硬上限，配合 512 格广播极易瞬间卡死场内所有客户端；发包开销随玩家数线性增长，多人同屏建议手动控制发包节奏。

发包烟花（假实体火箭）​

服务端仅下发“某处存在烟花实体”的数据包，由客户端在本地建构实体并模拟飞行。

  • 64 格裁剪只管本体：FireworkRocketEntity.shouldRenderAtSqrDistance 写死 distance < 4096.0（64264^2642），超出后不画火箭与尾迹；但 handleEntityEvent 处理爆炸粒子时无距离检查，远景观众会看到“无火箭升空、天上凭空炸开”。
  • 全生命周期依赖发包：服务端不托管该实体，必须严格按 创建 (AddEntity) →\rightarrow→ 元数据 (SetEntityData) →\rightarrow→ 爆炸 (EntityEvent) →\rightarrow→ 销毁 (RemoveEntities) 顺序发包。漏掉销毁包（如插件重载或报错中断）会导致客户端永久残留悬停火箭。
  • 固定加速度，无重力：客户端每 tick 令水平速度 ×1.15\times 1.15×1.15（撞方块退回 1.0）、垂直速度 +0.04+ 0.04+0.04；若 DATA_SHOT_AT_ANGLE = true 则变为匀速直线。没有重力抛物线，下坠轨迹只能靠中途补发速度包硬拼。
  • 炸点靠猜，中途进服不补发：地形碰撞在客户端本地闭环，服务端只能按初速度推算炸点；无实体追踪器，演出中途进服的玩家不会收到已升空烟花的补发包。
  • 音效与带宽限制：升空声由客户端首 tick 自动播放（音量写死 3.0）；爆炸声在 26.3 起才支持读取实体静音标记。每支烟花需向每位观众单发 5 个包（1.21.4 及更早为 4 个，无引爆前的静音更新包），含完整物品 NBT。

方案对比与选型​

维度普通粒子force 粒子发包烟花（假实体）
可视半径32 格（受相机与设置限制）512 格本体 64 格，爆炸无距离限制
客户端设置遵循粒子档位强制穿透不适用
超量表现随机漏点随机漏点，且挤占全局预算无数量上限，直接消耗帧率
空间精度极高（直接指定坐标）极高仅能理论推算，受碰撞影响
网络开销点数 × 玩家数点数 × 玩家数5 包 / 支 × 玩家数（含 NBT）

选型建议：需要精准摆点与远景轮廓（字形、几何阵列）用 force 粒子；需要原版烟花质感（升空尾迹、音效、炸裂）用发包烟花。演出中采用“近景烟花 + 远景粒子”混用，性价比最高。
